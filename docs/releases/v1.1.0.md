# Zynubo v1.1.0

The first Zynubo release: a userscript and independent Chromium/Firefox extensions sharing one YouTube engine.

## Changes

- Block ad requests and clean player responses, with consent-gated SponsorBlock and other optional community integrations.
- Customize YouTube through a redesigned Control Center with focused sections, search and aligned settings.
- Use a matching red Z identity across the panel, popup and browser icons.
- Keep page-engine status, temporary pause and technical counters accessible without a crowded dashboard.
- Preserve settings compatibility and prevent a second Zynubo page engine when both distribution formats are installed.

## Downloads and installation

- **Zynubo.user.js:** install through Tampermonkey or Violentmonkey, then reload YouTube.
- **Zynubo-chromium-v1.1.0.zip:** extract and load unpacked in Chrome, Brave or Edge using Developer mode. No userscript manager needed.
- **Zynubo-firefox-v1.1.0.zip:** extract and load its manifest temporarily from `about:debugging`. Unsigned; removed when Firefox closes.
- **Zynubo-source-v1.1.0.zip:** editable reviewer source; use Node 24.21.0 and `npm ci && npm run build`.
- **SHA256SUMS:** checksums of the exact four attached download files.

## Validation

- Build, license, version/hash, source-parity and reproducibility checks passed; 220 unit/contract cases passed.
- Chromium for Testing 149 and Firefox 157 passed temporary-profile installation/integration fixtures, including panel bounds/theme, duplicate prevention and the status bridge.
- All 22 UI fixture scenarios passed, including narrow layouts, search and keyboard focus; Firefox lint reported zero errors or warnings.
- Release automation repeats validation and verifies archive contents before publication.

## Limitations

- Live YouTube playback/ad blocking, actual mobile browsers and cross-device sync were not validated. Simulated pages and engine responses do not prove live blocking.
- Extension ZIPs are unsigned local packages. No Mozilla-signed XPI, store submission, approval or store listing is included.
- Pausing the page engine does not disable the extension's static browser network rules; disable the extension to stop those rules.
- DeArrow is userscript-only. Signed rule data retains its inherited trust key and revision; verification failures retain cached/built-in rules.
- Three known development-tool audit entries remain in web-ext's Android dependency chain; these dependencies are not bundled in the runtime. See the maintenance documentation.
