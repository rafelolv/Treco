# Treco v1.10.1

## Changes

- Point installation, updates, signed rule sources and support directly to rafelolv/Treco.
- Keep earlier official filter-source preferences and cached rules compatible with the renamed repository; custom sources remain unchanged.

## Downloads and installation

- **Treco.user.js:** update through Violentmonkey or Tampermonkey, then reload YouTube.
- **Treco-chromium-v1.10.1.zip:** extract and load unpacked in Chrome, Brave or Edge. Replace the existing local files and reload to update.
- **Treco-firefox-v1.10.1.zip:** extract and load as an unsigned temporary Firefox add-on.
- **Treco-source-v1.10.1.zip:** editable reviewer source and licenses. Build with Node 24, `npm ci` and `npm run build`.
- **SHA256SUMS:** checksums of the four attached downloads.

Keep one Treco installation enabled. See the [extension guide](https://github.com/rafelolv/Treco/blob/v1.10.1/docs/EXTENSIONS.md).

## Validation

Local checks cover unit/contract suites, versions, licenses, shared-engine parity and reproducible packages. Temporary extension integration passed in Chromium 149.0.7827.55 and Firefox 157.0; Firefox lint and the short synthetic video/comment/chat/navigation gate passed. All eight canonical signed-data endpoints matched the repository files byte-for-byte. Release automation repeats validation and checks downloaded assets. See [VALIDATION.md](https://github.com/rafelolv/Treco/blob/v1.10.1/docs/VALIDATION.md).

## Limitations

Browser checks use synthetic pages and simulated manager APIs; actual Violentmonkey installation and live YouTube playback/blocking were not verified. Local extensions need a manual update. Page-engine pause leaves extension browser network rules active. No browser-store submission or signed XPI is included. Earlier release assets remain unchanged.
