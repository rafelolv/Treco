# Zynubo v1.7.0

## Changes

- Set the current video to 0.25×–10× from Video tools and reset to 1× with one click.
- Redesign the Control Center and extension popup with clearer navigation, simpler settings and improved narrow layouts.
- Keep favorites and quick links in Overview, with activity and rule details available on demand.
- Preserve comments and player state by restricting data cleanup to reviewed ad fields.
- Leave live and replay chat outside page filtering and remove mixed-purpose telemetry blocks from the extensions.
- Add clear recovery actions and diagnostic reports you can review, copy or download with private details omitted.
- Confirm list replacements and migration imports, reject accidental double-clicks and keep JSON import undo available.
- Improve input labels, text contrast and keyboard navigation.
- Simplify installation instructions and check download links, icons, versions and published checksums automatically.

## Downloads and installation

- **Zynubo.user.js:** open with Violentmonkey or Tampermonkey, then reload YouTube.
- **Zynubo-chromium-v1.7.0.zip:** extract and load unpacked in Chrome, Brave or Edge. No userscript manager is needed.
- **Zynubo-firefox-v1.7.0.zip:** extract and load as a temporary Firefox add-on. The unsigned installation disappears when Firefox closes.
- **Zynubo-source-v1.7.0.zip:** editable reviewer source and licenses. Build with Node 24, `npm ci` and `npm run build`.
- **SHA256SUMS:** checksums of the four attached downloads.

Keep one Zynubo installation enabled. Local extensions need a manual update and reload; GitHub does not update them automatically. See the [installation guide](https://github.com/rafelolv/Zynubo/blob/v1.7.0/docs/EXTENSIONS.md).

## Validation

Local checks passed packaging, unit/contract suites, licenses, synchronized versions, identical shared engines and reproducible archives. The UI matrix passed 32 synthetic scenarios (39 including parent groups) in Chromium for Testing 149.0.7827.55. Temporary extension integration passed in Chromium 149.0.7827.55 and Firefox 157.0, including 10× and reset to 1×. Firefox lint had no errors, notices or warnings; the short video/comment/chat/navigation gate passed both builds.

Release automation repeats the checks before publication and verifies downloaded checksums afterward. Detailed evidence is in [VALIDATION.md](https://github.com/rafelolv/Zynubo/blob/v1.7.0/docs/VALIDATION.md).

## Limitations

Tests use simulated pages and manager APIs. Actual Violentmonkey installation and live YouTube playback/ad blocking were not verified. High speeds can silence audio in some browsers; playback speed is a manual action for the current recorded video and does not force a rate on later videos. Page-engine pause leaves extension browser network rules active. DeArrow remains userscript-only. No browser-store submission, store approval or signed XPI is included.
