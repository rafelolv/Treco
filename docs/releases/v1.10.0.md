# Treco v1.10.0

## Changes

- Rename Zynubo to Treco: The Complete YouTube Toolkit. All the tricks you need for a better YouTube.
- Introduce a T logo across the page interface, extension popup, userscript metadata and documentation.
- Show rafelolv as the userscript author and embed the current icon to avoid stale remote images.
- Keep old update endpoints and settings imports compatible while using Treco names for new downloads.

## Downloads and installation

- **Treco.user.js:** install or update with Violentmonkey or Tampermonkey and reload YouTube. Prefer updating the existing entry; keep one installation enabled.
- **Treco-chromium-v1.10.0.zip:** extract and load unpacked in Chrome, Brave or Edge.
- **Treco-firefox-v1.10.0.zip:** extract and load as an unsigned temporary Firefox add-on.
- **Treco-source-v1.10.0.zip:** reviewer source and licenses; build with Node 24, `npm ci` and `npm run build`.
- **SHA256SUMS:** checksums of the four attached downloads.

A separate manager installation can have separate storage. Export settings before moving to another entry; Treco accepts earlier Zynubo exports. Firefox identity and existing update URLs remain available.

## Validation and limits

Local unit/contract, package/version/license, reproducibility, Firefox lint, stability and browser integration checks passed. The Chromium 149.0.7827.55 UI matrix passed 34 synthetic scenarios; temporary extension integration also passed in Firefox 157.0. Current UI captures were visually reviewed. See docs/VALIDATION.md for details.

Actual userscript-manager installation/update, manager icon rendering and real YouTube playback/blocking were not validated. Browser tests use simulated pages and manager APIs. Page-engine pause leaves extension browser network rules active. No browser-store submission or signed XPI is included. Required MIT notices and source/service attribution remain in the distributed files.
