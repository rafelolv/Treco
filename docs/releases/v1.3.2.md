# Zynubo v1.3.2

Fix missing comment text while retaining targeted ad filtering.

## Changes

- Preserve framework entity updates that carry comment content and other page state.
- Prevent cached broad pruning rules and property traps from deleting that container.
- Include the recent header-only Zynubo button, Alt+Shift+Z shortcut, page-engine status and favorite settings.

## Downloads

Install Zynubo.user.js with Violentmonkey or Tampermonkey and reload existing YouTube tabs. Chromium ZIPs load unpacked; Firefox ZIPs are unsigned temporary installs. The source ZIP includes build instructions and licenses. SHA256SUMS covers the four attached files.

## Validation and limits

Targeted regressions reproduce broad framework deletion before the fix and preserve comment entities afterward. Local packaging checks cover unit/contract cases, source parity, versions and licenses. Release automation repeats its existing browser checks and verifies published checksums. Live YouTube comments and an actual Violentmonkey profile were not validated. Page-engine pause does not disable extension static network rules. No browser-store submission or signed XPI is included.
