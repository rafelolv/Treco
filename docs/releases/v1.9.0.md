# Zynubo v1.9.0

## Changes

- Adjust video speed directly from a compact button beside the player's settings, with a 0.25×–10× slider and reset to 1×.
- Keep the player speed control synchronized with native speed changes, fullscreen and replaced videos.
- Hide that button with **Video tools → Hide player speed button**. The choice is saved and panel speed controls remain available.

## Downloads and installation

- **Zynubo.user.js:** install or update with Violentmonkey or Tampermonkey, then reload YouTube.
- **Zynubo-chromium-v1.9.0.zip:** extract and load unpacked in Chrome, Brave or Edge. Replace the existing local files and reload to update.
- **Zynubo-firefox-v1.9.0.zip:** extract and load as a temporary Firefox add-on. This unsigned installation disappears when Firefox closes.
- **Zynubo-source-v1.9.0.zip:** editable reviewer source and licenses. Build with Node 24, `npm ci` and `npm run build`.
- **SHA256SUMS:** checksums of the four attached downloads.

Keep one Zynubo installation enabled. See the [extension installation guide](https://github.com/rafelolv/Zynubo/blob/v1.9.0/docs/EXTENSIONS.md).

## Validation

Local packaging, unit/contract suites, license checks, synchronized versions, identical shared engines and reproducible archives passed. The Chromium for Testing 149.0.7827.55 UI matrix covers native controls, fullscreen, narrow players, keyboard focus, navigation and the saved visibility preference. Temporary extension integration passed in Chromium 149.0.7827.55 and Firefox 157.0. Firefox lint and the synthetic video/comment/chat/navigation gate passed.

Release automation repeats validation before publication and verifies downloaded checksums. Detailed evidence and limits are recorded in [VALIDATION.md](https://github.com/rafelolv/Zynubo/blob/v1.9.0/docs/VALIDATION.md).

## Limitations

Tests use simulated pages and manager APIs. Actual Violentmonkey installation and live YouTube playback/native toolbar layouts were not verified. High playback rates may silence audio in some browsers. Speed changes apply manually to the current recorded video; they do not force a rate on later videos. Ads and live streams are excluded. Page-engine pause leaves extension browser network rules active. No browser-store submission or signed XPI is included.
